ライトノベル / ビジュアルノベル / 脚本向けのローカル優先デスクトップエディタ（Windows · Tauri 2）。

原稿はユーザーが指定したフォルダに保存されます。本文を独自サーバーへアップロードすることはありません。任意で **クラウドミラー**（例: Google Drive）を設定し、低頻度の同期によって複数端末での執筆を接続できます。

## ダウンロードとインストール

1. [Releases](https://github.com/Ngyama/LightScript/releases) から最新の Windows インストーラを入手します。
2. インストール後、スタートメニューから **LightScript** を起動します。
3. 初回起動時は、本機ディスク上に **ローカル作品庫** を選択してください（使用中の作品庫を Google Drive 直下に置かないでください）。
4. 複数端末を利用する場合は、設定で **クラウドミラー** を紐づけ、タイトルバーの **同期** から push / pull を行います。

未署名のインストーラは Windows SmartScreen に表示されることがあります（想定内の動作です）。出所を確認のうえ続行してください。アプリ内の更新確認は GitHub Releases 経由で行われます。

## プライバシー

| 動作 | 内容 |
|------|------|
| 執筆内容 | ローカル作品庫、およびユーザーが明示的に同期したクラウドミラーにのみ保持されます |
| ネットワーク | アプリ更新の確認・ダウンロード（GitHub）に限定されます。テレメトリや本文の AI 送信はありません |
| Google Drive など | クラウド同期クライアント配下に置いた場合、同期はそのクライアントが行い、LightScript のテレメトリではありません |

## 内容モデル

**Project（作品）→ Script（巻/章）→ Scene（場）**

- ディスク上: `project.json`（目録・キャラクター）+ `scripts/<id>/scenes/<id>.json`（Scene 本文）
- スナップショットは作品内 `.lightscript/backups/` に保存されます（既定ではクラウドへ同期しません）
- 最後に開いた Script / Scene はアプリローカル設定に記録され、作品フォルダには含まれません

## 同期に関する指針

1. **ローカル作品庫** が唯一の作業領域です（自動保存・Undo・スナップショットの対象）。
2. **クラウドミラー** は任意の複製です。継続的に同期中の Drive フォルダを、編集中のローカル作品庫として指定しないでください。
3. 推奨手順: 端末 A で執筆を終えた後に「クラウドへ同期」→ 端末 B で「クラウドから取得」してから編集を継続。
4. ローカルとクラウドの版が食い違う場合、次のいずれかを選択するよう提示されます: クラウド版を採用する、ローカル版を保持する、または双方を保持する。

## 執筆 UI と段落操作

画面構成は次のとおりです: 左に Script / Scene 軌道、上にキャラクターバーと Scene 情報、中央に段落の流れ、右下に文字数・行数。

本文はブロックの列です。各ブロックは **叙述** か **対話** のいずれか一方であり、同一段落内で混在できません。Enter により種類の切替または次段の挿入を行います。

| 種類 | 役割 | 見え方 |
|------|------|--------|
| **Narrative（叙述）** | 情景・行動・地の文 | 通常の本文 |
| **Dialogue（対話）** | 台詞 | `「」` 付き。「キャラ対話」モードでは左側に話者を表示 |

設定の **執筆モード**:

- **キャラ対話**: 対話に話者を表示します。Tab で話者メニューを開きます。
- **引用体**: 対話はキャラクターに紐づけず、話者も表示しません。空段落での Enter により叙述 / 対話は切り替わります。台詞には引き続き `「」` を用います。

### Enter：種類切替と改段

挙動は、段落が空かどうか、およびキャレット位置により異なります。

**叙述で Enter**

1. **段落が空**（空白のみ）→ **当該段落を対話に変換**（空の `「」` を挿入し、キャレットを括弧内へ）。新しい段落は作成しません。
2. **内容があり、キャレットが途中** → **キャレット位置で叙述を二段に分割**。
3. **内容があり、キャレットが末尾** → **下方に空の叙述を新規挿入**。

**対話で Enter**

1. **空とみなす**（空白、またはプレースホルダの `「」` のみ）→ **当該段落を叙述に変換**（プレースホルダを消去）。
2. **実質的な台詞がある** → **下方に新しい対話を挿入**（同様に `「」` 付き）。  
   - キャラ対話: 次の話者を可能な範囲で自動割当。Scene 内のキャラクターが 2 人以上で推定できない場合は話者メニューを開きます。  
   - 引用体: 新しい対話はキャラクター非紐づけです。

要約: 空段落での Enter は **種類の切替**、非空段落の末尾での Enter は **同種の次段作成**、叙述の途中での Enter は **分割** です。

### Backspace：空段落の削除

- **空の叙述**、または **空の対話**（`「」` のみを含む）で Backspace を押すと **段落を削除**し、直前の段落末尾へフォーカスを移します。
- Scene には最低 1 段落が残ります。残段落が 1 つのみの場合は削除できません。

### 矢印キー

- 段落の **最初の表示行** で ↑ → 前の段落へ移動（可能な範囲で横位置を維持）。
- **最後の表示行** で ↓ → 次の段落へ、同様の規則で移動。

### Tab（キャラ対話モードのみ）

- 対話段落にフォーカスがあるとき、**Tab** で話者メニューを開きます（Scene 内キャラクターが 2 人以上の場合に特に有用です）。
- 矢印キーと Enter で選択し、Esc または再度の Tab で閉じます。
- 引用体では、Tab は話者ショートカットとして機能しません。

### Undo とその他

- **Ctrl+Z / Ctrl+Y**: 現在の Scene に対する Undo / Redo（連続入力の結合、貼り付け、段落削除、種類変更などを含む）。
- タイトルバー: **インポート**、**エクスポート**、**同期**、**バックアップと復元**、**作品庫**、**設定**。
- グローバルキャラクターは上部バーで管理します。対話は作品レベルのキャラクターを参照します。

## 開発

```bash
npm install
npm run tauri:dev
npm test
npm run tauri:build
```

リリース: `v*` タグを push します。CI は `tsc` と `npm test` の後にドラフトリリースを構築します。
