# LightScript

一个面向轻小说 / 视觉小说 / 剧本写作的本地桌面文本编辑器。

## 项目结构

LightScript 用 **Project → Script → Scene** 三层结构组织写作内容：

- **Project**：一部作品。所有数据保存在你指定的本地仓库目录下。
- **Script**：项目下的一卷 / 一章 / 一集，由若干 Scene 组成。
- **Scene**：实际写作单元，一个 Scene 对应一个独立的写作窗口。

## 写作界面

写作页视觉中心从上到下依次为：

- **项目名**
- **当前 Scene 标题**
- **角色栏**
- **正文段落区**

## 段落编辑

每个 Scene 的正文由两种段落组成：

- **Narrative**（叙述）：常规文本段，描述场景、行为等。
- **Dialogue**（对话）：每段对话左侧带一个角色标识。

主要交互：

- 在叙述段落里按 **Enter**：
  - 当前段为空 → 切换为对话段。
  - 当前段有内容 → 在下方新建叙述段。
- 在对话段落里按 **Enter**：
  - 当前段为空 → 切换为叙述段。
  - 当前段有内容 → 在下方新建对话段，并尝试自动指派下一句的发言角色。
- 在空段落按 **Backspace** 可删除该段并跳回上一段。
- **方向键** 上下移动会按光标横向位置就近落到上 / 下一段的对应位置。
- 对话段按 **Tab** 可快速打开发言人选择菜单（场景内已有 ≥ 2 个角色时）。

右下角实时显示当前 Scene 的 **字数** 与 **行数**。
