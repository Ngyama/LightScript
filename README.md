本地优先的轻小说 / 视觉小说 / 剧本桌面编辑器。

## 下载与安装

1. 打开 [Releases](https://github.com/Ngyama/LightScript/releases)，下载最新的 Windows 安装包。
2. 安装完成后，从开始菜单启动 **LightScript**。
3. 首次运行时，请在 **本机磁盘** 上选择「本地作品库」文件夹（请勿将正在使用的作品库直接建立在 Google Drive 目录中）。
4. 如需跨设备使用，请在设置中绑定 **云端镜像** 文件夹，并通过顶栏「同步」进行推送与拉取。

未签名的安装包可能触发 Windows SmartScreen，属预期行为；确认来源后可继续安装。应用内可通过 GitHub Releases 检查更新。

## 隐私

| 行为 | 说明 |
|------|------|
| 写作内容 | 仅保存在本地作品库，以及用户主动同步至云端镜像的副本中 |
| 网络 | 仅用于检查与下载应用更新（GitHub） |
| Google Drive 等 | 若将文件夹置于云盘客户端中，由该客户端负责同步 |

## 内容结构

**Project（作品）→ Script（卷/章）→ Scene（场景）**

- 磁盘布局：`project.json`（角色与结构目录）+ `scripts/<id>/scenes/<id>.json`（Scene 正文）
- 快照位于作品内 `.lightscript/backups/`（默认不同步至云端）
- 最近打开的 Script / Scene 记录于应用本地设置，不写入作品目录

## 同步建议

1. **本地作品库** 为唯一工作区。
2. **云端镜像** 为可选副本；请勿将正在编辑的本地作品库指向处于实时同步中的 Drive 目录。
3. 推荐流程：设备 A 完成写作后执行「同步到云端」→ 设备 B 执行「从云端拉取」后继续编辑。
4. 当本地与云端版本不一致时，将提示用户在以下选项中择一处理：采用云端版本、保留本地版本，或两侧均保留。

## 写作界面与段落交互

编辑界面：左侧 Script / Scene 轨道、上方角色栏与 Scene 信息、中部正文段落流、右下角字数与行数统计。

正文由两种段落构成，**同一段落不可混用类型**；通过 Enter 在类型间切换或新建下一段：

| 类型 | 含义 | 外观（依写作模式略有不同） |
|------|------|---------------------------|
| **Narrative（叙述）** | 场景、动作、旁白 | 普通正文 |
| **Dialogue（对话）** | 台词 | 自动附带 `「」`；在「角色对话」模式下左侧显示发言人 |

设置中提供两种 **写作模式**：

- **角色对话**：对话段显示发言人；可使用 Tab 打开发言人菜单。
- **引号体**：对话不绑定角色、不显示发言人；空段上的 Enter 仍可切换叙述与对话，台词仍使用 `「」`。

### Enter：类型切换与换段

具体行为取决于当前段落是否为空，以及光标是否位于段末。

**在叙述段按下 Enter**

1. **当前段为空**（仅含空白）→ **将本段转换为对话**（填入空的 `「」`，光标置于引号内）。不新建下一段。
2. **当前段有内容，且光标位于段落中间** → **于光标处拆分为两段叙述**（前半保留于本段，后半成为下一段）。
3. **当前段有内容，且光标位于段末** → **在下方新建一段空叙述**。

**在对话段按下 Enter**

1. **当前段视为空**（空白，或仅含占位 `「」`）→ **将本段转换为叙述**（清除占位引号）。
2. **当前段含有实质台词** → **在下方新建一段对话**（同样附带 `「」`）。  
   - 角色对话模式：将尽量自动指派下一句发言人；若当前 Scene 中角色不少于 2 个且无法自动判定，则打开发言人菜单。  
   - 引号体模式：新建对话不绑定角色。

### Tab（仅「角色对话」模式）

- 焦点位于对话段时，按 **Tab** 打开发言人菜单（Scene 内角色不少于 2 个时尤为常用）。
- 可使用方向键与 Enter 选择，按 Esc 或再次按 Tab 关闭。
- 「引号体」模式下，Tab 不作为发言人快捷键。

### 撤销与其它

- **Ctrl+Z / Ctrl+Y**：针对当前 Scene 的撤销 / 重做（含连续输入合并、粘贴、删段、改类型等）。
- 全局角色于顶部角色栏管理；对话引用的是作品级角色。
